# مدیریت هزینه | Money Manager

اپلیکیشن نمونه مدیریت درآمد و هزینه با Flutter و Dart، رابط کاربری فارسی و راست‌چین.

## امکانات
- داشبورد موجودی، درآمد و هزینه
- ثبت تراکنش درآمد یا هزینه
- دسته‌بندی تراکنش‌ها
- مشاهده و حذف تراکنش‌ها
- گزارش مجموع درآمد، هزینه و مانده
- نمایش سهم دسته‌بندی هزینه‌ها
- ذخیره‌سازی محلی با SharedPreferences
- رابط کاربری تیره و فارسی

## اجرا
1. Flutter SDK و Android Studio را نصب کنید.
2. این پوشه را باز کنید.
3. در ترمینال اجرا کنید:
   ```bash
   flutter pub get
   flutter run
   ```
4. برای ساخت APK:
   ```bash
   flutter build apk --release
   ```
   فایل خروجی در `build/app/outputs/flutter-apk/app-release.apk` قرار می‌گیرد.
